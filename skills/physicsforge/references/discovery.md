# PhysicsForge — Discovery Engine

A systematic protocol for generating genuinely novel physics research directions.
This is not a search protocol (that is `deep-search.md`). It is a *creative synthesis*
protocol that uses cross-domain pattern matching, structured idea generation modes,
and a multi-stage quality filter to produce specific, tractable, significant research ideas
that have not been pursued before.

## WHEN TO USE

Trigger this protocol when the user asks:
- "What should I work on next?"
- "Find me an unsolved problem in [field]"
- "What are the most promising unexplored directions in [topic]?"
- "Generate novel research ideas for [domain]"
- "What hasn't been tried in [area]?"
- Any question about research discovery, ideation, or unexplored territory

**Important distinction**: deep-search.md finds what HAS been done.
This protocol finds what HASN'T been done — or what has been done in a different
field and could be transplanted.

## THE SEVEN CREATIVE MODES

Every idea generated by this protocol is classified by its creative mode. Each mode
targets a different type of novelty. The protocol must generate ideas from at least
5 of the 7 modes for any topic.

### MODE 1 — ANALOGY IMPORT

**Definition**: Identify a problem in field X that is mathematically or structurally
isomorphic to an unsolved problem in the target field. The solution method from X
may transfer directly.

**Mechanism**: Map the unsolved problem's structure → search for matching structure
in other fields → import the known solution → verify the mapping holds.

**Example**: The heat equation in d=1 is isomorphic to the Schrödinger equation in
imaginary time. Exact solutions of one map to exact solutions of the other. The
quartic partition function Z₀ via Bessel functions came from this class of analogy.

**Physics-specific sources to mine**:
- Condensed matter ↔ HEP (field-theoretic analogues of phase transitions)
- Classical mechanics ↔ QFT (variational methods, action principles)
- Information geometry ↔ QFT (Fisher metric on theory space)
- Random matrix theory ↔ quantum chaos / QFT
- Algebraic topology ↔ gauge theory
- Combinatorics ↔ Feynman diagrams
- Fluid dynamics ↔ gravitational equations (fluid-gravity correspondence)

**Output format**:
```
ANALOGY: [source problem] in [source field] ←maps to→ [target problem]
MAPPING: [explicit mathematical correspondence]
IMPORT: [what solution method transfers]
VERIFICATION NEEDED: [what assumptions must hold for the mapping]
FIRST STEP: [write the dictionary between the two systems explicitly]
```

### MODE 2 — TOOL TRANSPLANT

**Definition**: Identify a mathematical or computational technique well-developed in
field F that has NOT been applied to the target field, even though the target field
has a problem of the appropriate type.

**Mechanism**: Survey techniques used in adjacent fields → ask "which problems in
the target field have the same structural requirements as where this tool has been used?"
→ propose the application.

**Example**: Random matrix theory handles the statistics of eigenvalue distributions
with great power. The spectrum of L̂_λ is an eigenvalue distribution. RMT techniques
(Wigner semicircle law, level repulsion, universality classes) have not been applied
to the spectral geometry of quartic fluctuation operators in QFT.

**High-value tool sources**:
- Optimal transport theory (Wasserstein distances, couplings)
- Persistent homology / topological data analysis
- Tensor network methods (MERA, PEPS) from quantum information
- Category theory / topos theory
- Large deviation theory from probability
- Tropical geometry
- p-adic analysis
- Ergodic theory and dynamical systems
- Free probability theory
- Derived algebraic geometry

### MODE 3 — LIMITING CASE

**Definition**: Identify a parameter (coupling, dimension, number of fields, ratio of
scales) that existing work treats as fixed, and study the extreme limit.

**Why this works**: Exact results are often available in limits. Connecting the limit
to physical regimes can give new non-perturbative information.

**Parameter space to explore**:
- Dimension d: d→0, d→1, d→2, d→∞; non-integer dimensions (fractal)
- Coupling λ: λ→∞ (strong coupling), λ→-λ (imaginary coupling)
- Number of fields N: N→∞ (large-N limit, tractable), N=1/2 (fractional)
- Mass m: m→0 (massless limit), m→im (tachyonic), imaginary mass
- Spacetime signature: Euclidean→Lorentzian→ultralorentzian
- Temperature T: T→∞ (classical limit), T→0 (quantum gravity), T=iT (imaginary time without Wick rotation)
- Quantization: ℏ→0 (classical), ℏ→iℏ (no standard interpretation — what happens?)

### MODE 4 — SYMMETRY QUESTION

**Definition**: Identify a symmetry (explicit or hidden) of the existing framework
and ask what happens when it is (a) broken, (b) restored, (c) extended, (d) deformed.

**Types of symmetry modifications**:
- Breaking: add a term that violates the symmetry explicitly
- Gauging: promote a global symmetry to a local one
- Deforming: q-deform a symmetry algebra
- Extending: supersymmetry, higher-spin symmetry
- Restricting: impose a discrete subgroup instead of continuous
- Anomaly: does the symmetry have a quantum anomaly not yet studied?

**Example**: The quartic oscillator has Z₂ symmetry φ → -φ. What happens when
this is gauged? When it's promoted to a continuous U(1)? When it's broken by adding
a φ³ term? Each question opens a new research direction.

### MODE 5 — SCALE INSERTION

**Definition**: Identify a new dimensionless combination of parameters that hasn't
been studied as a fundamental parameter, and ask what physics it controls.

**Mechanism**: Build the full set of dimensionless groups from the problem's parameters
(Buckingham π). Find groups that appear in the formula but haven't been studied as
control parameters. Ask: what is the physics as this group varies from 0 to ∞?

**Example**: In the quartic oscillator, x = 3m⁴/4λ is the natural dimensionless
parameter. For large x (small coupling or large mass): weakly anharmonic.
For small x (large coupling or small mass): strongly anharmonic.
The transition at x ~ 1 defines a natural scale m* = (4λ/3)^{1/4} that hasn't
been studied as a natural length scale in 4D QFT.

What happens at the scale m*? Is there a phase transition? A spectral rearrangement?

### MODE 6 — CONTRADICTION HUNT

**Definition**: Find two established results that, if combined, produce a prediction
nobody has tested — or produce an apparent contradiction that resolves a known puzzle.

**Mechanism**: 
1. List the key quantitative results in the target area (with arXiv IDs)
2. For each pair of results, ask: "If both are true, what is the logical consequence?"
3. Find consequences that are (a) non-trivial and (b) not yet measured or proved

**Example**: 
- Result A: The vacuum energy in QFT diverges as Λ⁴ perturbatively.
- Result B: The spectral zeta function ζ'(0) is finite non-perturbatively.
- Consequence: The quartic divergence is entirely an artefact of the regularisation
  scheme. This implies that a physical observable computed via two different
  regularisation schemes should give the same finite answer — but this has not been
  explicitly verified for interacting theories. There is a calculable prediction here.

### MODE 7 — INVERSE PROBLEM

**Definition**: Flip the standard problem direction. Instead of "given the theory,
compute the observable", ask "given an observed pattern, what theory produces it?"

**Examples**:
- Standard: given a QFT, compute the vacuum energy.
  Inverse: given the observed dark energy density, what is the unique QFT whose
  quartic spectral geometry gives exactly this value?

- Standard: given a Hamiltonian, find the spectrum.
  Inverse: given the observed CMB power spectrum, what spectral geometry of the
  inflationary potential produced it?

- Standard: given a lattice model, find the phase diagram.
  Inverse: given a phase diagram with a specific topology, what is the minimal
  Hamiltonian that produces it?

Inverse problems are often tractable (the underdetermined case can still be
constrained) and frequently undeveloped because theorists prefer forward problems.

## FULL DISCOVERY PIPELINE

### Phase 1 — Landscape Mapping

Run the deep-search.md protocol in GAPS mode on the target domain.
This gives: what is known, what is the current frontier, what are the acknowledged
open problems.

Output: a landscape map that the creative phase builds from.

### Phase 2 — Seed Generation (20 seeds)

Apply all 7 modes to the landscape. For each mode, generate at minimum 2-3 seeds.
Format: one-sentence idea with mode label.

**Creative constraints to enforce**:
- At least 3 ideas must come from outside the target field entirely
- At least 2 ideas must involve a tool nobody in the field has used
- At least 1 idea must be contrarian (challenges a widely-accepted assumption)
- No idea may be a minor variation on an existing result

### Phase 3 — Development (top 10 seeds)

Score the 20 seeds on first-pass criteria and develop the top 10 in detail:

```
IDEA NAME: [2-5 words, evocative]
MODE: [one of the 7]
DOMAIN OF ORIGIN: [for modes 1-2: where the idea comes from]

CLAIM: [The precise mathematical or physical statement to prove/compute.
        Must be specific enough that a physicist can say "this is true" or "this is false".]

WHY NOVEL: [1-2 sentences: what in the existing literature does NOT include this]

FIRST STEP: [The specific first calculation or construction. Must be concrete enough
             that someone could start today. Maximum 3 sentences.]

RISK: LOW / MEDIUM / HIGH
[LOW: standard techniques apply; MEDIUM: new technique needed; HIGH: requires major new ideas]

SIGNIFICANCE: LOW / MEDIUM / HIGH
[HIGH: would change a fundamental picture; MEDIUM: advances the field;
 LOW: interesting but limited impact]

PHYSICSFORGE ROUTE: [which protocol validates this: gap-analysis / formula-prediction /
                     theory-bridge / derivation-lab / paper-analysis]
```

### Phase 4 — Novelty Verification

For each of the top 10 ideas, run a targeted web/arXiv search:
```
Search: [core terms of the idea] site:arxiv.org
Search: [author 1] [idea terms]
Search: [exact claim phrasing]
```

Classify each idea:
- `[DONE]` — cite the paper; remove from candidates
- `[ATTEMPTED, NOT SOLVED]` — note the paper and where it stopped; add to context
- `[ADJACENT]` — a related idea exists; clarify the distinction; keep if genuinely different
- `[NOVEL]` — no prior work found; confirm candidate

### Phase 5 — Scoring and Ranking

Score each `[NOVEL]` or `[ATTEMPTED, NOT SOLVED]` idea:

| Criterion | Weight | Definition |
|---|---|---|
| Novelty | 35% | 0-10: how distinct from existing work |
| Tractability | 30% | 0-10: feasibility for a PhD student |
| Significance | 25% | 0-10: impact if solved |
| Clarity | 10% | 0-10: precision of the stated claim |

`Combined = 0.35×N + 0.30×T + 0.25×S + 0.10×C`

Present top 5 as ranked idea cards with full details.

### Phase 6 — PhysicsForge Handoff

For each idea in the top 5, identify the appropriate PhysicsForge validation protocol:

| Idea type | Recommended first step | PhysicsForge protocol |
|---|---|---|
| New formula / dimensional | Compute the Π groups | formula-prediction.md |
| Gap in existing theory | Run 8-phase analysis | gap-analysis.md |
| Cross-framework claim | Map the bridge | theory-bridge.md |
| New derivation claim | Attempt the derivation | derivation-lab.md |
| Literature claim | Full claim audit | paper-analysis.md |

## QUALITY STANDARDS

An idea is NOT acceptable for the final list if:
- It is a variation on a known result with a different notation
- It is a known open problem stated in the literature (these belong in gap-analysis.md)
- The "first step" is impossible to start without solving the problem itself
- The claim is unfalsifiable

An idea IS acceptable if:
- A specific, falsifiable mathematical claim can be stated
- The claim does not obviously follow from published results
- A first calculation can be written down immediately
- The source of the idea (the cross-domain connection or limiting case) is explicit

## ENHANCED PIPELINE — v2.6 ADDITIONS

The base pipeline (Phases 1–6) generates ideas and validates them.
The following four additions strengthen the pipeline against documented
failure modes observed in test runs.

### ENHANCEMENT 1 — Adversarial Ideation Pass (between Phases 2 and 3)

**Problem solved**: Seeds that sound novel but are reframings of known results
get developed wastefully and only fail late in validation.

**Protocol**: After generating 20 seeds in Phase 2, run a Skeptic Pass before
selecting the top-N for development. The Skeptic persona is prompted:

> You are a hostile reviewer who has read every paper in this field. For each
> of the following 20 seeds, write the strongest objection in one sentence.
> Categorise each objection as one of:
> [REFRAMING]    — restates a known result in different words
> [SPECIAL_CASE] — solved in a limit or under simplification 30+ years ago
> [TRIVIAL]      — follows from symmetry or dimensional analysis alone
> [BLOCKED]      — known no-go theorem or obstruction
> [WEAK]         — significant flaw but not fatal
> [NONE]         — no strong objection, idea stands

Seeds tagged REFRAMING / SPECIAL_CASE / TRIVIAL / BLOCKED are removed from
the candidate pool. WEAK ideas proceed with a flag. NONE ideas proceed
cleanly.

**Expected effect**: 30–50% of seeds eliminated before development. Saves
Phase 3 effort and prevents Phase 6 rejections.

### ENHANCEMENT 2 — First-Equation Stress Test (within Phase 3)

**Problem solved**: Phase 3 self-scoring on Clarity is inflated when the CLAIM
sounds specific but the FIRST STEP cannot be made concrete.

**Protocol**: For each developed idea, the output template now requires:

```
FIRST EQUATION: [The literal first mathematical object to be computed.
A formula, integral, limit, or operator definition. NOT English prose.
If this cannot be written, the idea is not yet ready for development.]
```

If FIRST EQUATION cannot be filled formally — i.e., the idea reduces to a
research programme rather than a calculation — automatically reduce
the Clarity and Tractability scores by 3 points each. Flag as
"PROGRAMME, not CALCULATION".

**Expected effect**: Clarity and Tractability scores become honest. The user
sees clearly which ideas are ready-to-compute vs. which need formulation.

### ENHANCEMENT 3 — Failure-Mode Taxonomy Gate (between Phases 4 and 5)

**Problem solved**: Some ideas pass novelty (no prior paper exists) but fail
careful examination because they belong to known failure patterns.

**Protocol**: Each idea passing novelty is classified against:

```
FAILURE MODES TO CHECK
────────────────────────────────────────────────────────────────
[REFRAMING]      — Same physics, different language
[OBVIOUS_LIMIT]  — Result follows from a known limit
[CHANGE_OF_VARS] — Equivalent to a known result by substitution
[SYMMETRY_FORCED]— Result is forced by a known symmetry
[NO_GO_BLOCKED]  — Conflicts with a known no-go theorem
[ADJACENT_FIELD] — Solved in another field; just unaware
[ANTHROPIC]      — Answer depends on observer-selection effects
[SCHEME_DEP]     — Result is just a scheme-dependent finite term
[FORMAL_SYM]     — Symbolic manipulation without physical content
[NONE]           — Genuinely a new claim
────────────────────────────────────────────────────────────────
```

Prompt:
> "Examine this developed idea. Which (if any) failure modes apply?
> If [NONE], state explicitly why each failure mode does NOT apply.
> Be more strict than usual — false negatives cost more than false positives."

Auto-reject SCHEME_DEP, FORMAL_SYM, REFRAMING, OBVIOUS_LIMIT, CHANGE_OF_VARS.
Major-warning flag for NO_GO_BLOCKED, ANTHROPIC.
Redirect ADJACENT_FIELD ideas to theory-bridge.md for thorough check.

**Expected effect**: Catches ideas like "the counterterm origin paradox"
(SCHEME_DEP) before they consume validation effort.

### ENHANCEMENT 4 — Forced-Pair Triangulation (alternative to Phase 2)

**Problem solved**: Even with 7 modes prompted, the creative phase produces
ideas in the natural orbit of the target domain. Genuinely cross-disciplinary
combinations are underrepresented.

**Protocol**: Replace standard Phase 2 with constrained generation through
pre-selected unusual domain pairs:

1. Build a pool of 10 "outside fields" never mentioned in the Phase 1
   landscape map. Examples for typical physics queries:
   `category theory, p-adic analysis, optimal transport, persistent homology,
   tropical geometry, free probability, Hopf algebras, derived algebraic
   geometry, ergodic theory, computational complexity theory`

2. Sample 5 pairs (target_domain, outside_field). For each pair, prompt:
   > "You MUST generate 3 ideas that genuinely use [outside_field] to
   > approach [target_domain]. Ideas must use specific theorems, techniques,
   > or constructions from [outside_field] — not just analogy. If no such
   > ideas are possible, state which structural feature of [target_domain]
   > makes the application impossible."

3. The 15 constrained-generation ideas join the 20 from standard ideation.
   The Adversarial Pass winnows both pools.

**Expected effect**: Outside-field ratio rises from ~25% (random prompting)
to ~50% (forced). Genuine cross-domain ideas surface that would not
otherwise appear.

### Calibration measurements

A skill that improves should produce:
- Higher novel-to-developed ratio (current: 4/5 = 80% → target: >85%)
- Higher PhysicsForge survival rate (current: 2/4 = 50% → target: >65%)
- Lower wasted-development cost (Phase 6 rejections, currently 1/5 → target: <0.5/5)

If after a 5-run trial these metrics do not improve, the enhancements should
be rolled back. They add prompt complexity and must pay for that complexity
in measurable quality.

## WORKED EXAMPLE

**Domain**: Spectral geometry of quantum field theory vacuum energy

**Seed ideas generated (selection)**:

1. [ANALOGY_IMPORT] The spectral function of -□+V(x) on a Riemannian manifold is
   governed by the Chern character classes in index theory. No equivalent "spectral
   characteristic class" has been defined for the quartic fluctuation operator in QFT.
   Could a quartic analogue of the Atiyah-Singer index theorem give non-perturbative
   vacuum energy directly?

2. [TOOL_TRANSPLANT] Free probability theory (Voiculescu) handles the statistics of
   large random matrices via R-transforms. The eigenvalue distribution of L̂_λ is a
   random-matrix-like object when λ is treated as a random coupling. Has the
   R-transform of L̂_λ's spectral density been computed? This could give the
   non-perturbative spectral density sought in the paper.

3. [LIMITING_CASE] The quartic oscillator at λ→∞ (strong coupling limit) has been
   studied in d=0+1. What is the spectrum of -□ + λφ⁴ on ℝ⁴ in the limit λ→∞, m→0
   (massless strong coupling)? The Weyl law gives N(E)~E^{3}, and the spectral zeta
   function changes character. This limit is analytically tractable and not in the
   literature.

4. [SYMMETRY_QUESTION] The quartic operator L̂_λ = -□ + m² + λφ²/2 has a hidden
   conformal symmetry in the limit m→0. When λ≠0, this symmetry is broken. What
   is the anomalous dimension of the vacuum energy operator under this breaking?
   Is there a conformal anomaly coefficient that controls the finite part of ζ'(0)?

5. [SCALE_INSERTION] Define the "quarton length" L* = (4λ/3m⁴)^{1/4}, the length
   scale at which the dimensionless parameter x = 3m⁴/4λ = 1 and W(λ,k) transitions
   from free to interacting. Physics at the scale k ~ 1/L* has never been isolated
   as a distinct regime. What observable depends primarily on L* and is accessible
   to lattice QFT or DSE methods?

**Novelty check results**:
- Ideas 2 and 5 are novel after arXiv search
- Idea 1 has partial precedent in index theory (cite Gilkey) but the specific quartic
  application is new
- Ideas 3 and 4 are novel as precise computational claims

**Recommended for PhysicsForge validation**:
- Idea 2 → formula-prediction.md (compute R-transform)
- Idea 5 → gap-analysis.md + formula-prediction.md (find L* observable)

## v2.7 ADDITIONS — DEEP ARCHITECTURE

The four enhancements in v2.6 hardened the existing pipeline against
documented failure modes. The two enhancements in v2.7 change the
pipeline's structure: cross-engine triangulation broadens the search,
and seed expansion graphs convert isolated ideas into research programmes.

### ENHANCEMENT 5 — Cross-Engine Triangulation (deep architectural change)

**Problem solved**: A single creative pass — even with 7 modes — produces
ideas in the natural orbit of the model's training-data patterns for the
target domain. The same model, run with different system prompts and
personas, generates structurally different idea distributions. Ideas
appearing in MULTIPLE such runs are higher-confidence; ideas appearing in
only one are lower-confidence (but may still be the most original — both
ends of the bell curve matter).

**Protocol**: Replace single-call Phase 2 with three parallel calls,
each with a distinct persona. The three engines:

```
ENGINE A — SYNTHESIST
  System: "You are a polymath physicist who has worked deeply in 5
  different sub-fields. You see mathematical structures connecting
  disparate areas. You generate ideas by recognising isomorphisms
  across fields."
  Bias: cross-disciplinary analogies, structure-preserving maps

ENGINE B — CONTRARIAN
  System: "You are a contrarian physicist who challenges accepted dogma.
  You believe most 'standard' approaches contain hidden flaws. You
  generate ideas by identifying what the field assumes without proof."
  Bias: questioning assumptions, finding gaps in standard arguments

ENGINE C — CROSS-DISCIPLINE EXPLORER
  System: "You are a mathematician who has spent equal time in physics,
  computer science, and pure math. You see techniques in one field that
  should be applied to others. You generate ideas by tool transplantation."
  Bias: importing methods, applying mathematical machinery
```

Each engine generates 20 seeds independently. The three pools (60 seeds)
are combined for the adversarial pass, but each seed retains its engine
of origin. Engine agreement becomes a scoring signal:

```
ENGINE-AGREEMENT BOOST
─────────────────────────────────────────────────────
Seed appears in 3/3 engines:  +1.5 to combined score
Seed appears in 2/3 engines:  +0.7 to combined score
Seed appears in 1/3 engines:  no boost
```

A "seed appears in N engines" is determined by semantic similarity at
the claim level (seeds with overlapping core claims are clustered). This
is computed by passing all 60 seeds back to the model with a clustering
prompt: "group these seeds into equivalence classes by core claim".

**Cost**: 3× Phase 2 API cost. Acceptable when novelty quality matters
more than runtime.

**Expected effect**: 10–20% of seeds appear in 2+ engines (high-confidence
candidates). Diversity of the 60-seed pool is roughly 2× the diversity of
a 20-seed single-engine pool.

### ENHANCEMENT 6 — Seed Expansion Graph (cluster-not-isolate)

**Problem solved**: Mathematicians do not work on isolated ideas — they
work on clusters of related questions that together form a research
programme. A single seed in isolation is fragile; a seed surrounded by 3
strong related sub-questions reveals genuine territorial richness.

**Protocol**: After the adversarial pass narrows the seed pool to ~25–30
strong candidates, apply seed expansion. For each surviving seed, prompt:

> "This seed has potential. Generate 3 child variations:
>
> CHILD-S (SHARPENING): A mathematically more precise / specific version
>   of the parent. Replaces vague terms with explicit objects.
>
> CHILD-G (GENERALISATION): The same insight applied to a broader class.
>   What's the parametric family this is the special case of?
>
> CHILD-D (DUAL): The inverse problem or opposite direction. If parent
>   asks 'compute X given Y', dual asks 'compute Y given X'."

The expansion produces a parent-child graph:

```
PARENT seed: "Quarton length L* as lattice observable"
  ├── CHILD-S: "⟨φ(0)φ(L*)⟩ has a kink in d log G/dr at r=L*"
  ├── CHILD-G: "Every (m,λ) defines a one-parameter family of crossover
  │            scales L_n* = L*·(some function of n); is the spectrum
  │            controlled by a single L* or a tower?"
  └── CHILD-D: "Given an observed kink at scale r₀ in lattice data,
                what (m,λ) reproduces r₀ via L*(m,λ)=r₀?"
```

**Cluster richness scoring**: After children are also developed and scored,
each parent gets a cluster score:

```
cluster_score(parent) = 0.5 × parent_score + 0.5 × avg(child_scores)
```

This rewards parents whose children are themselves strong. A parent with
three weak children is an isolated peak (cluster_score < parent_score).
A parent with three strong children represents a research programme
(cluster_score > parent_score).

**The cluster is the unit of output**, not the individual idea. The final
ranked list shows clusters, with the parent as the headline and children
as expandable sub-ideas. A user pursuing a cluster has 4 related
calculations to attempt, not 1, which dramatically increases the chance of
landing on something tractable.

**Cost**: 1 additional API call (batched expansion of all surviving seeds
in one prompt). Modest cost increase for substantial structural improvement.

**Expected effect**:
- Best parents reveal themselves through cluster richness, not raw novelty
- Failed seeds (isolated peaks) are demoted automatically
- Output is structured as 5 research programmes rather than 5 individual ideas
- Users with weak parent ideas can pivot to a strong child instead of restarting

## INTEGRATION WITH OTHER PROTOCOLS

This protocol is the ENTRY POINT for a full research programme:

```
Discovery Engine
      │
      ▼
Top 5 Ideas
      │
      ├──→ gap-analysis.md    (map existing work on the idea)
      ├──→ formula-prediction.md (predict the formula for the claim)
      ├──→ theory-bridge.md   (if the idea bridges two frameworks)
      ├──→ derivation-lab.md  (attempt the first derivation)
      └──→ paper-analysis.md  (if an existing paper is nearly there)
```

An idea that passes PhysicsForge validation becomes a research proposal.
An idea that fails PhysicsForge validation teaches you why it fails — which is
also valuable information about the structure of the problem.
